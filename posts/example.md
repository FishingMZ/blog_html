# 欢迎使用 Markdown 编辑器 🚀

## 功能特性

- ✨ 实时预览
- 📤 上传 .md 文件（支持拖拽）
- 📥 下载为 .md 文件
- 🎨 符合 Material Design 3 规范
- 🌓 深色 / 浅色模式
- 📱 响应式布局

## Markdown 示例

### 文本样式

你可以使用 **粗体**、*斜体* 或 ~~删除线~~。

### 代码

行内代码：`const hello = 'world';`

代码块：
```javascript
function greet(name) {
  return `你好，${name}！`;
}
console.log(greet('MD3'));
```
